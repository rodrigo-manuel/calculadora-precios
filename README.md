# Calculadora de precios

Aplicación web instalable (PWA) para que un pequeño comerciante calcule el precio de venta de un producto a partir del costo, el flete y el margen de ganancia que quiere obtener.

**Usar en línea:** https://rodrigo-manuel.github.io/calculadora-precios/

## Qué calcula

A partir de la cantidad de unidades, el costo por unidad, el flete total y el porcentaje de ganancia:

- flete por unidad y costo real por unidad (costo + flete),
- precio de venta sugerido,
- ganancia por unidad y ganancia total,
- venta total.

Los valores se muestran en pesos colombianos y los campos se formatean con separador de miles mientras se escribe.

## Tecnologías

HTML, CSS y JavaScript sin librerías. Manifiesto web y *service worker* para instalarla en el celular y abrirla sin conexión.
